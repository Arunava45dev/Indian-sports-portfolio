
## AI Sports Scout
Athlete profiles include a profile-grounded AI scout, and /scout lets visitors compare two athletes or request a career summary in English, Hindi, Tamil, Telugu, Bengali, Marathi, Kannada, Malayalam, or Punjabi. Configure GROQ_API_KEY in ackend/.env with a key from Groq Console. GROQ_MODEL optionally selects a supported chat model. The API key stays on the backend and is never sent to the browser.
